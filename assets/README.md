# OpenSwap brand assets

OpenSwap uses the OpenSoft mark (the two half-rings) unchanged; only the word
is its own. The lockup is the mark, a gap of about a third of its width, then
"OpenSwap" in one weight (semibold) with tight tracking (−0.4 at 21 px). One
ink: `#0a0a0a` on light, `#ffffff` on dark. No gradients, no recolouring.

| File | Use |
|---|---|
| `opensoft-app-icon.svg` | The app icon: the mark on a black tile |
| `openswap-wordmark.svg` / `-white.svg` | The lockup. The word is set in the system sans (SF Pro on a Mac, Public Sans elsewhere); the mark is the only drawn shape |
| `openswap-wordmark-4x.png` / `-white-4x.png` | The lockup rendered with SF Pro, 704×128, for READMEs and decks |

In the app, the setup wizard draws the same lockup from `src/openswap/assets/opensoft-symbol-64.png` and the system font (`menubar_wizard.SetupWizard._lockup`).
